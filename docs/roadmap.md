# Project Roadmap

## Phase 1: Foundation
- define project goal and evaluation criteria
- create repo structure and documentation
- set up environment and dependencies

## Phase 2: Data Pipeline
- collect tool-calling examples
- clean dataset schema
- write preprocessing utilities

## Phase 3: Reward + Training
- implement deterministic validation reward
- configure LoRA + GRPO pipeline
- run baseline training experiment

## Phase 4: Evaluation
- validate structural correctness
- benchmark against baseline prompts
- measure schema compliance and tool-use success

## Phase 5: Iteration
- expand training corpus
- tune reward design and hyperparameters
- improve reliability and generalization
